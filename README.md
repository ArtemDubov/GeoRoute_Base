RouteOptima — построение оптимальных маршрутов по адресам

Веб-приложение на Streamlit для построения оптимального маршрута курьера по нескольким адресам. Загружает дорожный граф OpenStreetMap, считает кратчайшие пути алгоритмом Дейкстры и решает задачу коммивояжёра (TSP).

Возможности

- Поиск адресов через Nominatim (OpenStreetMap).
- Список из произвольного числа точек доставки; первая точка — депо.
- Автоматический подбор радиуса графа вокруг выбранных точек.
- Три критерия оптимизации маршрута: Расстояние (минимизация суммарной длины пути), Время (минимизация времени в пути с учётом скоростей дорог), Комфорт (предпочтение магистралей узким улицам с настраиваемыми коэффициентами по каждому типу дороги).
- Настройка коэффициентов комфорта для типов дорог: motorway, trunk, primary, secondary, tertiary, residential, living_street, service, unclassified.
- Отрисовка маршрута и связок от адресов к ближайшим узлам дорожной сети на интерактивной карте Folium.

Архитектура

Всё приложение — один файл app.py. Основные блоки:

- Поиск адресов — search_address через geopy.Nominatim с кэшем Streamlit.
- Загрузка графа — load_graph через osmnx.graph_from_point с приведением к неориентированному виду (ox.convert.to_undirected) и проекцией в метрическую систему координат (ox.project_graph).
- Матрицы весов — build_weight_matrices строит три симметричные разреженные CSR-матрицы (scipy.sparse.coo_matrix(...).tocsr()): distance, time, comfort.
- Кратчайшие пути — shortest_paths_matrix вызывает scipy.sparse.csgraph.dijkstra один раз с параметром indices=[...] для всех точек сразу.
- TSP — tsp_bruteforce (полный перебор перестановок, для N ≤ 7) и tsp_greedy (жадный алгоритм, для N > 7).
- Восстановление маршрута — build_full_route идёт по матрице предшественников от точки к точке и склеивает сегменты в один путь.

Требования

- Python 3.10+
- Зависимости из requirements.txt: streamlit, streamlit-folium, folium, geopy, osmnx, networkx, scipy, numpy, pyproj, scikit-learn.

Установка и запуск

Создайте виртуальное окружение и активируйте его:

    python -m venv .venv
    # Windows
    .venv\Scripts\Activate.ps1
    # macOS / Linux
    source .venv/bin/activate

Установите зависимости:

    pip install -r requirements.txt

Запустите приложение:

    streamlit run app.py

Откройте в браузере http://localhost:8501.

Как пользоваться

1. В боковой панели введите адрес в поле поиска (лучше без номера дома: "город, улица").
2. Выберите подходящий вариант из выпадающего списка и нажмите "Добавить точку".
3. Добавьте минимум две точки. Первая точка в списке считается депо.
4. Выберите критерий оптимизации: Расстояние, Время или Комфорт.
5. Если выбран «Комфорт», при необходимости раскройте блок «Коэффициенты комфорта», поменяйте значения и нажмите «Применить коэффициенты».
6. Нажмите «Построить маршрут». Дождитесь загрузки графа — на первом запросе это 10–30 секунд, дальше граф кэшируется.
7. Результат появится в основной области: метрики длины и времени, метод решения, порядок посещения и линия маршрута на карте.

Пример тестового набора

1. Москва, Красная площадь — депо.
2. Москва, Парк Горького.
3. Москва, ВДНХ.
4. Москва, МГУ.

Выберите критерий «Расстояние» и постройте маршрут. Приложение покажет оптимальный порядок объезда и суммарную длину.

Использованные алгоритмы и сложности

| Задача | Функция | Сложность |
| --- | --- | --- |
| Кратчайшие пути от всех точек | dijkstra из scipy.sparse.csgraph | O((V+E) log V) |
| TSP, полный перебор | tsp_bruteforce | O(N!) |
| TSP, жадный алгоритм | tsp_greedy | O(N^2) |
| Восстановление пути | reconstruct_path | O(V) |

Ограничения

- Публичный Nominatim медленный, на один поиск 1–2 секунды.
- Граф загружается из OSM — в редких районах данные могут быть неполными.
- Полный перебор TSP работает до 7 точек включительно, дальше включается жадный алгоритм.
- Пропускные способности дорог и пробки не учитываются.
