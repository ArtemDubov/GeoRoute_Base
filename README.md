# RouteOptima — построение оптимальных маршрутов по адресам

Веб-приложение на Streamlit для построения оптимального маршрута курьера
по нескольким адресам. Загружает дорожный граф OpenStreetMap, считает
кратчайшие пути алгоритмом Дейкстры и решает задачу коммивояжёра (TSP).

## Возможности

- Поиск адресов через Nominatim (OpenStreetMap).
- Список из произвольного числа точек доставки; первая точка — депо.
- Автоматический подбор радиуса графа вокруг выбранных точек.
- Три критерия оптимизации маршрута:
  - **Расстояние** — минимизация суммарной длины пути.
  - **Время** — минимизация времени в пути с учётом скоростей дорог.
  - **Комфорт** — предпочтение магистралей узким улицам с настраиваемыми
    коэффициентами по каждому типу дороги.
- Настройка коэффициентов комфорта для типов дорог (`motorway`, `trunk`,
  `primary`, `secondary`, `tertiary`, `residential`, `living_street`,
  `service`, `unclassified`).
- Отрисовка маршрута и связок от адресов к ближайшим узлам дорожной сети
  на интерактивной карте Folium.

## Архитектура

Всё приложение — один файл `app.py`. Основные блоки:

- **Поиск адресов** — `search_address` через `geopy.Nominatim` с кэшем
  Streamlit.
- **Загрузка графа** — `load_graph` через `osmnx.graph_from_point` с
  приведением к неориентированному виду (`ox.convert.to_undirected`) и
  проекцией в метрическую систему координат (`ox.project_graph`).
- **Матрицы весов** — `build_weight_matrices` строит три симметричные
  разреженные CSR-матрицы (`scipy.sparse.coo_matrix(...).tocsr()`):
  `distance`, `time`, `comfort`.
- **Кратчайшие пути** — `shortest_paths_matrix` вызывает
  `scipy.sparse.csgraph.dijkstra` один раз с параметром `indices=[...]`
  для всех точек сразу.
- **TSP** — `tsp_bruteforce` (полный перебор перестановок, для N ≤ 7) и
  `tsp_greedy` (жадный алгоритм, для N > 7).
- **Восстановление маршрута** — `build_full_route` идёт по матрице
  предшественников от точки к точке и склеивает сегменты в один путь.

- Python 3.10+
- Зависимости из `requirements.txt`:
  - `streamlit`
  - `streamlit-folium`
  - `folium`
  - `geopy`
  - `osmnx`
  - `networkx`
  - `scipy`
  - `numpy`
  - `pyproj`
  - `scikit-learn`
