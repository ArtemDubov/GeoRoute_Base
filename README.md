# Заготовка Streamlit-фронтенда для веб-приложения с построением оптимальных маршрутов

Это минимальный каркас веб-приложения для практической работы по маршрутизации.
Фронтенд уже умеет искать адрес через OpenStreetMap/Nominatim и ставить одну
точку на интерактивную Folium-карту с подложкой CartoDB.

Остальная логика специально не реализована: Вы должны самостоятельно
добавить несколько точек, импортировать граф дорожной сети, расчитать веса ребер,
кратчайшие пути и реализовать оптимизацию порядка посещения точек с выводом на интерактивную карту.

## Что есть в проекте

- `app.py` — весь код Streamlit-приложения.
- `requirements.txt` — минимальные зависимости для запуска фронтенда.
- `README.md` — описание проекта и инструкция.

Архитектура намеренно однофайловая, чтобы студентам было проще читать код и
понимать, куда добавлять свою алгоритмическую часть.

## Как запустить

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
streamlit run app.py
```

После запуска Streamlit покажет локальный адрес, обычно:

```text
http://localhost:8501
```

## Как работает фронтенд

1. Пользователь вводит адрес в поле поиска.
2. Приложение отправляет запрос в Nominatim, сервис геокодирования OpenStreetMap.
3. Если найдено несколько вариантов, они появляются в выпадающем списке.
4. Пользователь выбирает один адрес и нажимает кнопку постановки точки.
5. Координаты выбранного адреса сохраняются в `st.session_state`.
6. Folium-карта с подложкой CartoDB перерисовывается и показывает один маркер.

Если выбрать новый адрес, старая точка заменится новой. Это сделано специально:
данный проект является стартовым фронтендом, а не готовым маршрутизатором.

## Основные места в `app.py`

- `get_geolocator()` создает клиент Nominatim.
- `search_address(query)` ищет адрес и возвращает список найденных вариантов.
- `create_map(point)` создает карту и добавляет маркер выбранной точки.
- `st.session_state.selected_point` хранит текущую точку.
- `st.session_state.search_results` хранит последние результаты поиска.

## Задание

Вам необходимо расширить этот шаблон и реализовать:

- добавление нескольких точек вместо одной;
- удаление конкретной точки из списка;
- загрузку дорожного графа через OSMnx;
- расчет весов ребер по расстоянию, времени и дополнительному критерию;
- алгоритм кратчайшего пути;
- построение матрицы расстояний между точками;
- оптимизацию порядка объезда точек;
- отображение итогового маршрута на карте.

## Важное замечание про Nominatim

Nominatim — публичный сервис OpenStreetMap. Он не предназначен для массовых
нагрузочных тестов. В коде добавлена небольшая задержка между запросами и кеш
результатов поиска через Streamlit.

По умолчанию поиск ограничен Россией:

```python
COUNTRY_CODES = "ru"
```

Если нужно искать по всему миру, эту константу можно изменить или убрать
параметр `country_codes` в функции `search_address`.
